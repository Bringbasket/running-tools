# 工具箱模块

工具箱用于放置不依赖邮件系统的本地计算和运营辅助工具。每个工具都应有独立页面，
并将页面、类型、测试和说明保留在 `modules/tools/` 内。

## 当前工具

### 保本测算

路径：`/tools/pricing`

提供账号保本倍率、推荐售价倍率、保本单价、利润试算、账号额度反推和定价公式审计。
输入只在浏览器内使用，不调用后端接口、不写入 `data/`，刷新页面即可清空输入。

计算口径：

- 保本倍率 = 成本 ÷（额度 × 汇率 ×（1 − 综合损耗率））；
- 推荐倍率 = 保本倍率 ×（1 + 目标利润率）；
- 利润试算按额度全部售空估算；
- 额度反推使用“对应额度 ÷ 已知占比”计算总额度。

## 扩展约定

新增工具时，在 `frontend/` 下建立页面和组件，在本模块 `docs/` 记录输入、输出和计算
口径，并在 `module.ts` 中增加导航和路由。无需后端的工具不得新增无意义的 API 或状态
文件；需要服务端能力时，应先补充 API、鉴权和数据边界说明。
